# Support

## Start with the owning repository

Use [the repository map](docs/repositories.md) to open a reproducible issue in the repository that owns
the affected package, product behavior, identity source, or edge policy.

Use this repository for:

- broken ecosystem navigation;
- unclear adoption paths;
- cross-repository architecture questions;
- inconsistent maturity or evidence language;
- proposals that genuinely affect more than one source boundary.

Include exact revisions, environment details, commands, expected behavior, actual behavior, and sanitized
logs. Never include credentials, tokens, cookies, private design files, internal URLs, or personal data.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be reported publicly.
